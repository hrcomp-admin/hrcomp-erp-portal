# ERP 포털 메뉴 복구판

- `index.html`만 교체해도 메뉴가 즉시 표시됩니다. 메뉴 데이터의 초기 스냅샷이 HTML 안에 포함되어 있기 때문입니다.
- `js/menu-config.js`가 정상 로드되면 해당 최신 설정으로 다시 렌더링합니다. 실패 시 내장 스냅샷이 유지됩니다.
- `js/portal.js`는 이번 버전에서 로드하지 않습니다. 기존 파일은 삭제하지 않아도 됩니다.
- 향후 `menu-config.js`의 URL이나 활성 상태를 바꿀 때는 해당 파일이 실제로 배포되는지 반드시 확인하십시오. 외부 설정 로딩에 실패하면 HTML 내장 스냅샷이 표시됩니다.
- 브라우저 F12 Console에서 외부 메뉴 설정 로딩 경고가 있는지 확인하십시오.
- 로그인 사용자 정보는 아직 연결되지 않았습니다.
